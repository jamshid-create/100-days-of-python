# 🏝️ Treasure Island

A text-based adventure game where the player makes decisions to find the hidden treasure.

## 📌 About

This project was created as part of my learning journey through the **100 Days of Code – The Complete Python Pro Bootcamp** by Angela Yu.

The player navigates through a series of choices, and each decision leads to a different outcome. The goal is to make the right choices and find the treasure.

## 🧠 What I Learned

* Conditional statements (`if`, `elif`, `else`)
* Nested `if` statements
* Logical decision-making with multiple conditions
* Code blocks and indentation
* Using `.lower()` to handle user input consistently

## 🛠️ Technologies

* Python

## ▶️ How to Run

Make sure Python is installed on your computer.

Run the following command from the project directory:

```bash
python main.py
```

## 🎮 How to Play

Follow the instructions displayed in the terminal and choose your actions to progress through the adventure.

Choose the correct paths to find the treasure and win the game.

## 💻 Example

```text
Welcome to Treasure Island.
Your mission is to find the treasure.

You're at a cross road. Where do you want to go?
Type "left" or "right"

left

You've come to a lake. There is an island in the middle of the lake.
Type "wait" to wait for a boat. Type "swim" to swim across.

wait

You arrive at the island unharmed. There is a house with 3 doors.
One red, one yellow and one blue. Which colour do you choose?

yellow

You found the treasure! You Win!
```
