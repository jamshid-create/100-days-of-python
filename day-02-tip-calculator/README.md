# 🧮 Tip Calculator

A simple Python program that calculates how much each person should pay when splitting a bill, including a selected tip percentage.

## 📌 About

This project was created as part of my learning journey through the **100 Days of Code – The Complete Python Pro Bootcamp** by Angela Yu.

The program asks for the total bill, the desired tip percentage, and the number of people sharing the bill. It then calculates the total amount including the tip and determines how much each person should pay.

## 🧠 What I Learned

* Mathematical operations
* Data types
* Type conversion
* f-Strings
* Using `round()` to round numerical values

## 🛠️ Technologies

* Python

## ▶️ How to Run

Make sure Python is installed on your computer.

Run the following command from the project directory:

```bash
python main.py
```

## 💻 Example

```text
Welcome to the tip calculator!
What was the total bill? $100
How much tip would you like to give? 10, 12 or 15? 10
How many people to split the bill? 4
Each person should pay: $27.5
```
