# 🃏 Blackjack

A Blackjack game built in Python as the first **Capstone Project** of the course, combining concepts learned throughout the previous days.

## 📌 About

This project was created as part of my learning journey through the **100 Days of Code – The Complete Python Pro Bootcamp** by Angela Yu.

The game allows the player to play Blackjack against the computer. The player can choose to draw additional cards or pass, while the computer follows its own game rules.

This project brings together multiple Python concepts learned throughout Days 1–10 to build a complete playable game.

## 🧠 What I Learned

* Combining multiple Python concepts to build a complete project
* Structuring a program using multiple functions
* Using docstrings to describe functions
* Managing game state throughout the program
* Implementing Blackjack game rules
* Handling the Ace as either `11` or `1` depending on the current score
* Using loops and conditional logic to control the game flow

## 🛠️ Technologies

* Python

## 🎮 How to Play

1. Run `main.py`.
2. Choose whether you want to play.
3. The player and computer are each dealt two cards.
4. Choose whether to draw another card or pass.
5. The computer draws cards according to the game rules.
6. The final scores are compared to determine the result.

## 💻 Example

```text
Do you want to play a game of Blackjack? Type 'y' or 'n': y

Your cards: [10, 6], current score: 16
Computer's first card: 9

Type 'y' to get another card, type 'n' to pass: n

Your final hand: [10, 6], final score: 16
Computer's final hand: [9, 10], final score: 19

You Lose
```
