# 🎯 The Number Guessing Game

A number guessing game built in Python as part of the **100 Days of Code – The Complete Python Pro Bootcamp** by Angela Yu.

## 📌 About

In this project, the computer randomly chooses a number between 1 and 100, and the player tries to guess it.

The player can choose between two difficulty levels, which determine the number of attempts available.

## 🧠 What I Learned

* Understanding and applying **scope**
* Using **global constants**
* Managing game difficulty and remaining attempts

## 🛠️ Technologies

* Python

## 🎮 How to Play

1. Run `main.py`.
2. Choose a difficulty: `easy` or `hard`.
3. Try to guess the number between 1 and 100.
4. After each guess, the game tells you whether your guess is too high or too low.
5. Guess the correct number before running out of attempts.
