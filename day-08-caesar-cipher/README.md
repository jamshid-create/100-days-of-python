# 🔐 Caesar Cipher

A simple Caesar Cipher program built in Python that can encrypt and decrypt messages by shifting letters in the alphabet.

## 📌 About

This project was created as part of my learning journey through the **100 Days of Code – The Complete Python Pro Bootcamp** by Angela Yu.

The program allows the user to encode or decode a message by choosing a shift number.

## 🧠 What I Learned

* Creating functions with inputs (parameters)
* Passing arguments to functions
* Using function parameters to control the program's behavior
* Using the modulo operator `%` to wrap around the alphabet
* Using a `while` loop to run the program repeatedly

## 🛠️ Technologies

* Python

## ▶️ How to Run

1. Make sure Python is installed.
2. Run `main.py`.
3. Choose `encode` or `decode`.
4. Enter your message.
5. Enter the shift number.

## 💻 Example

```text
Type 'encode' to encrypt, type 'decode' to decrypt:
encode

Type your message:
hello

Type the shift number:
2

Here is the encoded result: jgnnq
```
