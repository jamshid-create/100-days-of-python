# 🔐 Password Generator

A Python program that generates a random password based on the number of letters, symbols, and numbers chosen by the user.

## 📌 About

This project was created as part of my learning journey through the **100 Days of Code – The Complete Python Pro Bootcamp** by Angela Yu.

The user chooses how many letters, symbols, and numbers they want in their password. The program randomly selects the required characters, shuffles their order, and generates the final password.

## 🧠 What I Learned

* Using `for` loops to repeat actions
* Using `range()` to control the number of repetitions
* Adding elements to a list with `append()`
* Using `random.choice()` to randomly select an item
* Using `random.shuffle()` to randomly reorder list elements
* Iterating through a list with a `for` loop
* Building a string from list elements

## 🛠️ Technologies

* Python

## ▶️ How to Run

Make sure Python is installed on your computer.

Run the following command from the project directory:

```bash
python main.py
```

## 🎮 How to Use

When prompted, enter the number of:

* Letters
* Symbols
* Numbers

The program will generate a password containing the requested number of each character type and randomly shuffle their order.

## 💻 Example

```text
Welcome to the PyPassword Generator!
How many letters would you like in your password?
8
How many symbols would you like?
3
How many numbers would you like?
4

Your Password is: aB7#kP2!x$9Lm4
```
