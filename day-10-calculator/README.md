# 🧮 Calculator

A simple calculator program built in Python that performs basic mathematical operations and allows the user to continue calculating with the previous result.

## 📌 About

This project was created as part of my learning journey through the **100 Days of Code – The Complete Python Pro Bootcamp** by Angela Yu.

The calculator supports addition, subtraction, multiplication, and division. The user can continue calculating with the previous result or start a new calculation.

## 🧠 What I Learned

* Storing functions as values in a dictionary
* Using a dictionary to select and call functions dynamically
* Passing arguments to functions using keyword arguments
* Using recursion by calling a function from within itself
* Building an interactive program that can continue from a previous result

## 🛠️ Technologies

* Python

## ▶️ How to Run

1. Make sure Python is installed.
2. Run `main.py`.
3. Enter the first number.
4. Choose a mathematical operation.
5. Enter the next number.
6. Choose whether to continue with the result or start a new calculation.

## 💻 Example

```text
What's the first number?: 10
+
-
*
/
pick an operation: *
What's the next number?: 5

10.0 * 5.0 = 50.0

Type 'y' to continue calculating with 50.0, or type 'n' to start a new calculation: y
```
