# 🎮 Higher Lower Game

A Higher Lower game built in Python as the final **Capstone Project** of the beginner section of the **100 Days of Code – The Complete Python Pro Bootcamp** by Angela Yu.

## 📌 About

In this project, the player compares two accounts and tries to guess which one has more followers.

The game continues as long as the player's guesses are correct. Each correct answer increases the score, while an incorrect guess ends the game.

## 🧠 What I Learned

* Working with a **list of dictionaries**
* Accessing data from dictionaries
* Combining multiple Python concepts to build a complete project
* Managing game state such as the score and game continuation

## 🛠️ Technologies

* Python

## 🎮 How to Play

1. Run `main.py`.
2. Two accounts are displayed.
3. Choose which account has more followers by typing `A` or `B`.
4. If your guess is correct, your score increases and the game continues.
5. If your guess is incorrect, the game ends and your final score is displayed.

## 💻 Example

```text
Compare A: Instagram, a Social media platform, from United States

    VS

Against B: Cristiano Ronaldo, a Footballer, from Portugal

Who has more followers? Type 'A' or 'B': A

You're right! Current score: 1
```

## 📂 Files

* `main.py` — Contains the game logic and program flow.
* `game_data.py` — Contains the account data used in the game.
* `art.py` — Contains the ASCII game logo and VS graphic.
