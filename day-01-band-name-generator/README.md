# 🎸 Band Name Generator

A simple Python program that generates a potential band name based on the user's city and pet's name.

## 📌 About

This project was created as part of my learning journey through the **100 Days of Code – The Complete Python Pro Bootcamp** by Angela Yu.

The program asks the user for the name of the city they grew up in and their pet's name, then combines them to generate a potential band name.

## 🧠 What I Learned

- Using the `print()` function
- Getting user input with `input()`
- Storing data in variables
- Working with strings
- Combining strings using the `+` operator

## 🛠️ Technologies

- Python
