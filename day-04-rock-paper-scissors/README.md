# 🪨📄✂️ Rock Paper Scissors

A simple command-line Rock Paper Scissors game where the player competes against the computer.

## 📌 About

This project was created as part of my learning journey through the **100 Days of Code – The Complete Python Pro Bootcamp** by Angela Yu.

The player chooses Rock, Paper, or Scissors, while the computer makes a random choice. The program then compares both choices and determines the winner.

## 🧠 What I Learned

* Working with Python lists
* Accessing list elements using indexes
* Using the `random` module
* Generating random numbers with `random.randint()`
* Combining multiple conditions with `and`
* Using nested conditional logic
* Validating user input

## 🛠️ Technologies

* Python

## ▶️ How to Run

Make sure Python is installed on your computer.

Run the following command from the project directory:

```bash
python main.py
```

## 🎮 How to Play

When prompted, enter:

* `0` for Rock
* `1` for Paper
* `2` for Scissors

The computer will randomly select its choice, and the program will determine the result.
