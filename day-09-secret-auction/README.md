# 🔨 Secret Auction

A Python program that simulates a secret auction where multiple bidders can enter their bids and the program determines the highest bidder.

## 📌 About

This project was created as part of my learning journey through the **100 Days of Code – The Complete Python Pro Bootcamp** by Angela Yu.

Each bidder enters their name and bid. The program stores the bids and determines the winner with the highest bid.

## 🧠 What I Learned

* Working with dictionaries
* Adding key-value pairs to a dictionary
* Accessing dictionary values using keys
* Looping through a dictionary
* Finding the highest value in a dictionary

## 🛠️ Technologies

* Python

## ▶️ How to Run

1. Make sure Python is installed.
2. Run `main.py`.
3. Enter your name and bid.
4. Continue entering bids for additional bidders.
5. Type `no` when all bidders have entered their bids.
6. The program displays the winner and their highest bid.

## 💻 Example

```text
What is your name?: Alice
What is your bid?: $150
Are there any other bidders? Type 'yes' or 'no'.
yes

What is your name?: Bob
What is your bid?: $200
Are there any other bidders? Type 'yes' or 'no'.
no

The winner is Bob with a bid of $200.
```
